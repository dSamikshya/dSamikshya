#### 🖥️ [Console App — Java IMS](https://github.com/dsamikshya/inventory-management-console)

> The origin — a pure Java console application with no frameworks, no database, no internet required. Built to master OOP fundamentals and file-based persistence.

| Feature | Details |
|---|---|
| 🗂️ Modules | Products, Categories, Suppliers, Customers, Batches |
| 💾 Storage | File-based persistence via plain `.txt` files |
| 🔍 Search | Query results auto-logged to `query_results.txt` |
| ☕ Pure Java | No frameworks — raw OOP, services, models, exceptions |
| 🖥️ Platform | Runs anywhere with JDK 17+ |

`Java` `OOP` `File I/O` `Console UI`

<details>
<summary>🚀 Quick Start</summary>

```bash
# Compile
javac -d out -sourcepath src src/Main.java

# Run
java -cp out Main

# One-liner
javac -d out -sourcepath src src/Main.java && java -cp out Main
```

Data is auto-saved to a `data/` folder on every operation.

</details>
